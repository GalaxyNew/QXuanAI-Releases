# QXuanAI 客户端与运行环境公开发行中心

本仓库为 **青玄 AI 音乐（QXuanAI）** 官方客户端免密公开发行中心。

## 📦 发行版下载说明

客户端提供三种运行架构形态：
1. **全量独立版 (Full Package)**：包含离线完整 Python 运行环境、PyTorch/CUDA 推理引擎、RVC 伴奏模型与全量资产，开箱即用无需依赖云端推理。
2. **按需组件版 (Component Package)**：包含核心计算组件与基础模型，适合本地资源受限但具备基础运行环境的用户。
3. **轻量云端版 (Cloud / Installer)**：仅包含轻量客户端，任务全部调度至青玄云端服务器执行。
